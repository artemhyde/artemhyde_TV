**Плеер для «Волны»: Aura Music с нашими правками**
Что это: готовых файлов здесь нет, только патчи (разности к исходникам) и скрипт сборки. Исходники скачиваются с github.com/TeamAuraMusic/AuraMusic, тег `v3.2.0`, коммит `2e4f1263`.
Лицензия: Aura Music распространяется под GPL-3.0, полный текст лежит рядом (`LICENSE-Aura.txt`). Папка `aura/` тоже под GPL-3.0, а не под MIT основного репозитория. Это изменённая версия, правки ноября 2026 года.

**Зачем своя сборка**
Обычная Aura умеет включать трек только через поиск. При промахе она играет первое попавшееся, новое находит не с первого раза, а опоздавший ответ включает музыку после закрытия. Правки это убирают.

**Что дают патчи**
`playFromMediaId("id/<videoId>/...")`: трек запускается сразу по точному id, без поиска и базы.
`ACTION_HARD_STOP`: плеер пуст, файлы очереди стёрты, и пока не придёт новая команда, ни разморозка, ни кнопки громкости, ни медиакнопки музыку не включат.
Адрес потока следующего трека можно получить заранее (`VOLNA_PRELOAD`). Очередь один трек, своё продолжение Aura не добавляет, возврат звука музыку не включает.
Каналы одного аккаунта: `VOLNA_PROFILE`, лайки и подборки от имени канала. Куки остаются внутри Aura, наружу уходят только названия и id треков.
Отдельный пакет `app.glasstv.aura`: можно поставить рядом с обычной Aura. Эти команды принимаются только от «Волны», подписанной тем же ключом.
Код получения потока (`YTPlayerUtils`, `potoken`, список клиентов) патчи не меняют.

**Что нужно для сборки**
git, JDK 21, Android SDK с платформой 36 и build-tools 36, ваш ключ подписи (`bash build/new-key.sh`). Подпись должна совпадать с подписью «Волны». NDK не нужен: заглушка распознавания песен из сборки убрана.
Запуск: `bash aura/build-aura.sh`, результат: `out/aura.apk`. Первая сборка скачивает около 1,5 ГБ и идёт дольше получаса, на машине автора ровно столько это заняло в первый раз.
