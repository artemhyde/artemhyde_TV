# Установщик HYDE TV

Одна программа для установки HYDE TV без Claude: человеку не нужны ни Git, ни Java, ни Python. Тот же установщик потом зовёт и Claude вместо ручных команд, так механизм установки один (план Codex, этап 2).

**Что умеет сейчас (заход 1)**  
Только чтение, на телевизоре ничего не меняет:
- находит телевизоры в сети (mDNS через adb), подключается, сопрягается по коду с экрана ТВ;
- читает паспорт ТВ: модель, Android, профиль (TCL Google TV, другой Google TV или не подходит), что есть: подсветка TCL, Dolby, панель TCL, Key Mapper, главный экран;
- строит план изменений по выпуску: что поставит, какие права выдаст, что поменяет, и как каждое изменение вернёт откат;
- сверяет файлы выпуска с описью (размер и SHA-256).

Дальше по плану: установка по плану с журналом (apply), продолжение после обрыва (resume), проверка (verify) и откат (restore).

**Запуск**  
Положите файл установщика в папку выпуска (там manifest.json и APK), рядом папку platform-tools с adb, и запустите. Откроется окно мастера в браузере этого компьютера.

Команды для окна команд (их же использует Claude):

```
hyde-install                          окно мастера в браузере
hyde-install devices                  ТВ в сети и уже подключённые
hyde-install connect адрес[:порт]     подключиться (адрес и порт с главного экрана «Беспроводная отладка»)
hyde-install pair адрес:порт код      сопряжение по коду из окна «Подключить устройство с помощью кода»
hyde-install inspect [--tv адрес] [--json] [--save файл]       паспорт ТВ
hyde-install plan [--tv адрес] [--release папка] [--with м1,м2] [--without м3] [--home] [--json]
```

Модули: guard, keymapper, home, nightmode, sound, picture, clip, keyboard, volna, browser. По умолчанию план берёт то же, что мастер в CLAUDE.md на ответ «реши сам»: «Сторож», «Дом», «Ночной режим», «Вставка», клавиатура, Key Mapper, «Звук» и «Картинка» там, где они работают, плитки к стоящим приложениям; главный экран прежний (`--home` делает «Дом» главным).

**Что откуда берётся**  
`recipe.json`: рецепт установки, какие приложения в каком порядке и с какими правами, у каждого изменения обратная команда. Те же шаги словами в CLAUDE.md, шаги 7 и 9: меняются вместе. Рецепт вшит в программу.  
Опись выпуска `manifest.json` (её пишет `build/release.sh`): файлы, версии, суммы, подпись, сторонние приложения.  
Паспорт ТВ: одна команда в оболочке ТВ собирает ровно нужные свойства, без серийного номера, MAC и идентификаторов. Правила уровня TCL те же, что у «Сторожа» (`apps/guard/src/app/glasstv/guard/CapsRules.java`): совпадение проверяет тест.

**Безопасность окна**  
Сервер слушает только 127.0.0.1 на случайном порту. Каждый запрос несёт случайный ключ из адреса страницы (после знака #), а адрес в запросе обязан совпадать с адресом сервера: другие страницы в браузере не могут управлять установщиком. Без действий 30 минут установщик закрывается сам. Наружу он не ходит: только adb к телевизору.

**Сборка и проверки**  
Нужен Go 1.27 с go.dev (в `~/.glasstv/tools/go` или в PATH).

```
bash installer/build.sh
```

Сначала `go vet` и `go test` (проверки на обезличенных паспортах настоящих ТВ в `testdata`: TCL 65C6K и виртуальный Google TV), потом файлы в `out/installer/` для Windows, macOS (Apple и Intel) и Linux, и SHA256SUMS. Сборка повторяемая: тот же коммит даёт те же байты.
