# Установщик HYDE TV

Одна программа для установки HYDE TV без Claude: человеку не нужны ни Git, ни Java, ни Python. Тот же установщик потом зовёт и Claude вместо ручных команд, так механизм установки один (план Codex, этап 2).

**Что умеет**
- находит телевизоры в сети (mDNS через adb), подключается, сопрягается по коду с экрана ТВ;
- читает паспорт ТВ: модель, Android, профиль (TCL Google TV, другой Google TV или не подходит), что есть: подсветка TCL, Dolby, панель TCL, Key Mapper, главный экран;
- строит план изменений по выпуску: что поставит, какие права выдаст, что поменяет, и как каждое изменение вернёт откат;
- ставит по плану (apply): перед первым изменением сверяет файлы выпуска с описью и подписью ключа выпуска, сверяет подпись уже стоящих приложений HYDE, снимает ТВ «до» и пишет журнал ledger.tsv (тот же, что у мастера, строка пишется до команды);
- после обрыва связи тот же apply продолжает незаконченную установку этого ТВ с того же места, сделанное пропускает;
- проверяет результат (verify): держится ли каждое изменение из журнала и работает ли «Сторож»;
- откатывает (restore) как tools/make-restore.sh: обратные команды от последней к первой, прежний главный экран после включения отключённого, повтор при мгновенном сбое связи, «отменять нечего» для того, чего уже нет, в конце сверка со снимком настроек, которые меняются мимо журнала. Установок этого ТВ несколько (установка, потом обновление): откат идёт по всем, от новой к старой;
- обновляет поверх стоящего выпуска: что на ТВ уже так (права, белый список, главный экран), не выполняет заново и не пишет в журнал, поэтому откат одного обновления ничего не отнимает; права администратора «Ночного режима» перед обновлением снимает и потом возвращает;
- после каждой команды проверяет, держится ли изменение, и при «прошло, но не держится» повторяет, потом честно предупреждает (служба «Сторожа» поднимается не мгновенно);
- скачивает adb с сайта Google, если его нет на компьютере, только по согласию человека с условиями Google: версия, размер и SHA-1 из официального списка SDK Google записаны в описи выпуска;
- показывает и переключает выключатели «Сторожа» после установки: отладка по сети (держать всегда или ещё 2 часа и выключить) и записки с телефона.

Главный экран меняется как home_switch в tools/tv.sh: «Дом» открывается, роль меняется, кнопка «Домой» проверяется, не вышло: всё возвращается. Главный экран Google TV (launcherx) и его страховка отключаются на TCL до смены (иначе роль не меняется), на Google TV других марок только если «Домой» всё равно открывает launcherx. Кнопки на ТВ установщик нажимает только при согласии «ТВ свободен». Сторонние приложения (Key Mapper) скачиваются только при согласии, по списку из описи, с проверкой подписи.

**Запуск**  
Из архива выпуска (`build/package.sh`): распаковать и запустить `hyde-install`, выпуск он найдёт в папке `release/` рядом с собой. Иначе установщик ищет manifest.json рядом с собой, в текущей папке или по `--release`. Откроется окно мастера в браузере этого компьютера.  
adb ищется рядом с установщиком, в `~/.glasstv/tools` (в том числе скачанный им самим), в Android SDK (ANDROID_HOME, место Android Studio по умолчанию) и в PATH; нет нигде: окно мастера и `hyde-install get-adb` предлагают скачать его с сайта Google.  
Папка HYDE TV у человека: `~/.glasstv` (или GLASSTV_HOME): `tools` (adb), `downloads`, `backup` (снимки «до» и журналы). Журналы лежат здесь, а не рядом с выпуском: следующий выпуск, скачанный в другую папку, найдёт прежние установки этого ТВ.

Команды для окна команд (их же использует Claude):

```
hyde-install                          окно мастера в браузере
hyde-install get-adb [--yes]          скачать adb с сайта Google (с согласием с условиями Google)
hyde-install devices                  ТВ в сети и уже подключённые
hyde-install connect адрес[:порт]     подключиться (адрес и порт с главного экрана «Отладка по Wi-Fi»)
hyde-install pair адрес:порт код      сопряжение по коду из окна «Подключить устройство с помощью кода подключения»
hyde-install inspect [--tv адрес] [--json] [--save файл]       паспорт ТВ
hyde-install plan [--tv адрес] [--release папка] [--with м1,м2] [--without м3] [--home] [--json]
hyde-install apply [как plan] [--backup папка] [--allow-download] [--tv-free] [--yes]
hyde-install verify [--tv адрес] [--backup папка]
hyde-install restore [--tv адрес] [--backup папка] [--yes]   все установки этого ТВ от новой к старой (одна: --backup папка_журнала)
hyde-install guard adb [always|service] [--tv адрес]   отладка по сети: держать всегда или ещё 2 часа
hyde-install guard notes [on|off] [--tv адрес]         записки с телефона
```

Коды выхода apply и restore: 0 готово, 1 не прошло (что именно, напечатано выше), 3 связь с ТВ пропала (запустите ещё раз). Журналы в `~/.glasstv/backup/<метка>`: снимок «до» (с android_id телевизора, поэтому папка остаётся только на этом компьютере), журнал, ход установки (session.json: в нём и то, что на ТВ было уже до этой установки).  
Путь с Claude: `AGENT.md`, в архиве выпуска он лежит под именем CLAUDE.md. Claude зовёт эти же команды с `--json` там, где нужен разбор ответа.

Модули: guard, keymapper, home, nightmode, sound, picture, clip, keyboard, volna, browser. По умолчанию план берёт то же, что мастер в CLAUDE.md на ответ «реши сам»: «Сторож», «Дом», «Ночной режим», «Вставка», клавиатура, Key Mapper, «Звук» и «Картинка» там, где они работают, плитки к стоящим приложениям; главный экран прежний (`--home` делает «Дом» главным).

**Что откуда берётся**  
`recipe.json`: рецепт установки, какие приложения в каком порядке и с какими правами, у каждого изменения обратная команда. Те же шаги словами в CLAUDE.md, шаги 7 и 9: меняются вместе. Рецепт вшит в программу.  
Опись выпуска `manifest.json` (её пишет `build/release.sh`): файлы, версии, суммы, подпись, сторонние приложения.  
Паспорт ТВ: одна команда в оболочке ТВ собирает ровно нужные свойства, без серийного номера, MAC и идентификаторов. Правила уровня TCL те же, что у «Сторожа» (`apps/guard/src/app/glasstv/guard/CapsRules.java`): совпадение проверяет тест.

**Безопасность окна**  
Сервер слушает только 127.0.0.1 на случайном порту. Каждый запрос несёт случайный ключ из адреса страницы (после знака #), а адрес в запросе обязан совпадать с адресом сервера: другие страницы в браузере не могут управлять установщиком. Без действий 30 минут установщик закрывается сам. Наружу он ходит только по согласию человека и только по адресам из описи выпуска: adb с dl.google.com и Key Mapper с GitHub; остальное время только adb к телевизору.

**Сборка и проверки**  
Нужен Go 1.27 с go.dev (в `~/.glasstv/tools/go` или в PATH).

```
bash installer/build.sh
```

Сначала `go vet` и `go test` (проверки на обезличенных паспортах настоящих ТВ в `testdata`: TCL 65C6K и виртуальный Google TV), потом файлы в `out/installer/` для Windows, macOS (Apple и Intel) и Linux, и SHA256SUMS. Сборка повторяемая: тот же коммит даёт те же байты.
