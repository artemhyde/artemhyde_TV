**Инструменты**
Что это: скрипты, которыми мастер (Claude) работает с ТВ и сборкой. Все пишут по-русски, параметры и способ запуска описаны в шапке каждого файла. Bash-скрипты работают в Git Bash на Windows и в bash на macOS и Linux. Нужны только adb и Python 3, остальное находится само.  
Адрес ТВ: переменная `TV` (например `TV=192.168.0.10:5555`) или ключ `--tv адрес`. Путь к adb: переменная `ADB` или PATH, затем `~/.glasstv/tools/platform-tools`.  
Правило: скрипты ничего не меняют на ТВ молча. Команды, которые что-то меняют (`off`, `inst`, `tiles_install`, `play_install`), мастер сначала объясняет вам, потом запускает, и они отказываются работать без журнала `LEDGER` (откат строится из него).  
Рабочая папка снимков и разбора экрана: `TV_WORK`, по умолчанию `backup/.tv-work` (в git не попадает: в разборах экрана бывают названия сетей и аккаунты).

**Для мастера установки**
`find-tv.sh`: найти ТВ через mDNS, подключиться по адресу, проверить связь (`--pair` для сопряжения по коду; без порта сам ищет порт через mDNS). Код выхода 0 готов, 2 разрешить на экране ТВ, 3 не отвечает, 4 нужно сопряжение. Сканирования сети не делает.  
`snapshot.sh`: снимок ТВ «до» в `backup/<метка>/` (только чтение) и пустой журнал `ledger.tsv`.  
`make-restore.sh`: собрать `restore.sh` из журнала в обратном порядке; `--dry-run` печатает команды и ничего не пишет.  
`paste-to-tv.sh`: вставить на ТВ текст с ПК в поле ввода (нужно приложение «Вставка с ПК», `app.glasstv.clip`).  
`screen-mirror.sh`: экран ТВ в окне на ПК, если стоит scrcpy (необязательно).  
`windows/tv-screen.ps1`, `windows/tv-paste.ps1`, `windows/tv-link.ps1`: то же для Windows без bash (общая часть поиска и подключения в `tv-link.ps1`).

**Помощники для управления экраном (подключаются командой `source tools/tv.sh`)**
`tv.sh`: функции `key`, `shot`, `dumpui`, `tapt`, `focus_texts`, `dpad_to`, `goto_tile`, `row_names`, `ledger`, `off`, `inst`, `home_switch`, `tiles_install`, `play_install`, `rc_push`, `rc_press`, `km_new_map`, `km_new_long`.  
`off` отключает только пакеты из `data/tcl-packages.tsv` и никогда из `data/tcl-never-touch.txt`, а пакеты главного экрана только внутри `home_switch`; `inst` ставит apk и сама решает, какую обратную команду писать (откат удаляет только то, чего до нас не было; обновление не откатывается удалением, данные остаются); `home_switch` меняет главный экран с проверкой кнопки «Домой» и сама возвращает как было, если не вышло; `tiles_install` ставит только плитки, чьё приложение-цель уже стоит; `play_install` жмёт OK, только если фокус на «Установить» и нет цены.  
`km_new_map` и `km_new_long` (раскладка Key Mapper) целиком на живом ТВ не проверялись: после каждого вызова сверяйте экран, при сбое функция остановится и скажет шаг.  
`ui.py`: разбор дерева экрана (`uiautomator dump`): подписи с рамками, координаты нужного элемента или тексты внутри элемента в фокусе (`--focus`).  
`tvui.py`: управление меню настроек из Python: кнопки, дерево экрана, пункт в фокусе.  
`row.py`, `rowlist.py`: ряды плиток на главном экране (где фокус, сколько нажатий до нужной плитки). Размеры рассчитаны на экран 1920x1080.

**Проверки без телевизора**
`tests/test-tv.sh`: `inst`, `off`, `home_switch` и собранный `restore.sh` против подставного ТВ (сбои, обрыв связи, чужая подпись, права администратора). Запуск `bash tools/tests/test-tv.sh`, код 0: всё прошло.

**Измерение плавности**
`rowbench.sh`: 8 нажатий вправо и влево по плиткам и сводка по пропущенным кадрам (`bash tools/rowbench.sh before`).  
`fstats.py`: разбор `dumpsys gfxinfo <пакет> framestats` по стадиям кадра.  
`fsum.py`: то же одной строкой.

**Отчёты об установке**
`reports/collector.gs`: копия кода приёма у автора (веб-приложение Google Apps Script при его таблице). С 1.2.0 приходит два вида, оба только при галочке «Отправлять автору технические отчёты» в начале мастера (в командах её выключает `--no-report`): отчёт установщика в конце установки, обновления и возврата (лист «Отчёты») и суточная сводка «Сторожа» (лист «Устройства», строка на ТВ по случайному номеру устройства; с 1.2.1 в ней ещё погода и курсы «Дома», колонки появляются со скриптом версии 4, прежний эти поля молча пропускает). Приём проверяет каждое поле, лишнее отбрасывает, IP, MAC и почту вырезает; публично по тому же адресу видна только сводка по моделям и версиям. Новая версия вставляется в редактор скриптов таблицы, затем один раз `setup` и новое развёртывание с прежним адресом (шапка файла).

**Двойник пульта**
`rc-double/`: JSON-файлы для команды `hid` на ТВ. Описание в `rc-double/README.md`.

**Что здесь не проверено**
Скрипты, которые работают с живым ТВ, проверены только на синтаксис: на этапе сборки репозитория ТВ не использовался. Рабочими они считаются по записям проекта, где те же команды выполнялись на TCL 65C6K.
