# С чего начать

Сначала проверьте телевизор: Google TV или Android TV на Android 12 и новее ([compatibility.md](compatibility.md)). Номер Android: Настройки, Система, «Об устройстве», строка «Версия ОС Android TV».

**Выберите путь**
- Компьютер с Windows, macOS или Linux, без Claude: скачайте архив выпуска для своей системы со страницы Releases и запустите установщик. Окно мастера в браузере проведёт по шагам: [install/windows.md](install/windows.md) (на macOS и Linux то же окно, отличается только запуск).
- С Claude Code: тот же архив, откройте распакованную папку в Claude Code и напишите «давай начнём». Claude спросит, что вам нужно, и поставит тем же установщиком: [install/agent.md](install/agent.md).
- Свой ключ подписи или свои правки: сборка из исходников с Claude по [CLAUDE.md](../CLAUDE.md). Это режим разработчика: нужны инструменты сборки, и это долго.
- Точные команды без окна мастера, для поддержки и проверок: [install/manual.md](install/manual.md).
- Только посмотреть, что получится: снимки экранов в [README](../README.md) и описание с пульта в [guide.md](guide.md).
- С телефона Android без компьютера: проверенного способа пока нет.

**Что понадобится в любом пути**  
Компьютер и телевизор в одной домашней сети. Пульт: один раз включить на телевизоре «Отладка по Wi-Fi» и ввести в окне мастера шестизначный код с экрана телевизора. Сама установка на виртуальном Google TV заняла около полуминуты; сколько уйдёт на включение отладки и выбор, зависит от вас и вашей сети.
