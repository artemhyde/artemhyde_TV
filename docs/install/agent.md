# Установка с Claude

Claude ставит HYDE TV тем же установщиком, что окно мастера: тот же план, тот же журнал и тот же откат. Сам он команд на телевизоре не выдумывает: всё, что меняет телевизор, делает `hyde-install`, а Claude объясняет, спрашивает и помогает, если что-то пошло не так.

**Как начать**
1. Скачайте архив выпуска для своей системы со страницы Releases и распакуйте его.
2. Откройте распакованную папку в Claude Code (claude.com/claude-code) и напишите «давай начнём».
3. Дальше Claude ведёт по шагам: проверит компьютер (при необходимости предложит скачать adb с сайта Google, условия Google принимаете вы), поможет включить на телевизоре отладку и подключиться, прочитает паспорт телевизора, спросит по одному, что ставить, покажет план и после вашего «да» поставит.

Инструкция, по которой работает Claude, лежит в архиве под именем CLAUDE.md (в репозитории это [installer/AGENT.md](../../installer/AGENT.md)). Это обычный текст: прочитайте его, прежде чем доверять.

**Что Claude спросит у вас прямо**
- Принимаете ли условия Google для adb (если adb на компьютере нет).
- Что ставить и делать ли «Дом» главным экраном.
- Можно ли скачать Key Mapper с GitHub (если он нужен для кнопок пульта).
- Свободен ли телевизор: при смене главного экрана установщик открывает «Дом» и нажимает «Домой».
- Оставить ли отладку по сети и записки с телефона включёнными.

**Чего Claude не делает никогда**  
Не просит и не вводит пароли от аккаунтов (код сопряжения с экрана телевизора не пароль). Не принимает условия за вас и не нажимает «Разрешить» на телевизоре. Не ищет расширения и источники для Lampa. Не отправляет наружу журналы установки: в них идентификатор телевизора.

**Чем Claude полезнее окна мастера**  
Отвечает на вашем языке, объясняет каждый шаг, ведёт по назначению кнопки пульта в Key Mapper (может смотреть снимки экрана телевизора), разбирает ошибки и подскажет, что делать, если телевизор пропал из сети. Если чего-то нет в инструкции, Claude так и скажет, а не будет пробовать вслепую.

**Свой ключ и сборка из исходников**  
Это отдельный путь, для тех, кто хочет подписать приложения своим ключом или поменять код: скачайте репозиторий, откройте его папку в Claude Code и напишите «давай начнём». Claude работает по [CLAUDE.md](../../CLAUDE.md) репозитория: ставит инструменты сборки, собирает и ставит по шагам.
