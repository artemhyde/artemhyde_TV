# Команды установщика

Для тех, кто хочет без окна мастера, для поддержки и проверок. Команды те же, что зовёт Claude. Выпуск 1.0.0, установщик 0.3.

**Где запускать**  
В распакованной папке архива: в Windows PowerShell `.\hyde-install.exe <команда>`, в Git Bash `./hyde-install.exe <команда>`, на macOS и Linux `./hyde-install <команда>`. Без команды открывается окно мастера; `hyde-install help` печатает список.

**По порядку**
```
hyde-install get-adb                        adb с сайта Google, спросит согласие с условиями Google
hyde-install devices                        телевизоры в сети и уже подключённые
hyde-install pair 192.168.1.20:41235 123456 сопряжение: адрес, порт и код из окна «Подключить устройство с помощью кода подключения»
hyde-install connect 192.168.1.20:37123     подключение: адрес и порт с главного экрана «Отладка по Wi-Fi»
hyde-install inspect                        паспорт телевизора, только чтение
hyde-install plan --home                    план: что поставит, что поменяет, как вернёт; только чтение
hyde-install apply --home --tv-free         установка по плану, перед началом спросит «Ставить по этому плану?»
hyde-install verify                         держится ли каждое изменение из журнала, жив ли «Сторож»
hyde-install guard adb                      отладка по сети: показать; always держать, service ещё 2 часа и выключить
hyde-install guard notes                    записки с телефона: показать; on или off
hyde-install restore                        откат всех установок этого телевизора, от новой к старой
```

**Ключи**  
`--tv <адрес>`: какой телевизор, если подключено несколько (без него установщик молча не выбирает).  
`--with volna,browser` и `--without keymapper`: модули сверх выбора по умолчанию или без них. Модули: guard и home (обязательны), keymapper, nightmode, sound, picture, clip, keyboard, volna, browser.  
`--home`: сделать «Дом» главным экраном (по умолчанию главный экран остаётся прежним, если «Дом» уже не главный).  
`--allow-download`: согласие скачать Key Mapper 4.6.2 с GitHub (подпись сверяется с описью).  
`--tv-free`: телевизор свободен, установщик может открыть «Дом» и нажать «Домой» (нужно при смене главного экрана).  
`--yes`: не спрашивать подтверждение. `--json` у inspect и plan: ответ для программ. `--release <папка>`: другой выпуск. `--backup <папка>`: другая папка журналов, у restore и verify ещё и одна папка журнала вместо всех.

**Коды выхода**  
connect: 0 подключено (последняя строка `TV=<адрес>`), 2 нажмите «Разрешить» на телевизоре, 3 телевизор не отвечает, 4 нужно сопряжение.  
apply и restore: 0 готово, 1 не прошло (что именно, напечатано выше), 3 связь пропала: подключитесь заново и запустите ту же команду, apply продолжит с того же места, повтор restore безвреден.  
verify: 0 всё держится, 1 что-то нет.

**Где что лежит**  
`~/.glasstv/tools/platform-tools`: adb, если его скачал установщик.  
`~/.glasstv/backup/<дата-время>/`: одна установка. Снимок «до» (settings-global.txt, settings-secure.txt, settings-system.txt, списки пакетов, state.txt), паспорт телевизора (passport.txt), журнал ledger.tsv (время, что сделано, команда, обратная команда; строка пишется до команды), ход установки session.json. В снимке есть идентификатор телевизора: папка остаётся только на этом компьютере, никуда её не отправляйте.  
В Windows `~` это `C:\Users\<имя>`, папка `.glasstv` скрыта не всегда, но начинается с точки.

**Что прислать, если нужна помощь**  
Вывод `hyde-install inspect` (в нём модель, Android и что найдено, без серийного номера и адресов) и текст ошибки. Отчёт «Сторожа» без личных данных: кнопка «Отчёт» на его экране. Журналы и снимок из `~/.glasstv/backup` не присылайте.

**Совсем без установщика**  
Вернуть главный экран и отключённое вручную командами adb: [rollback.md](../rollback.md), «Вернуть вручную, если скрипта нет».
