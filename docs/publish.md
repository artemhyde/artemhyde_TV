# Как залить проект на GitHub

Это инструкция для тех, кто хочет выложить свою копию проекта (например, друзьям). Через сайт GitHub папку заливать неудобно: в браузере за раз не больше 100 файлов и не больше 25 МБ на файл, а здесь файлов больше сотни. Поэтому GitHub Desktop, без командной строки. Пять шагов.

**Прежде чем начать**  
Попросите Claude проверить папку проекта на личное: адреса сети и устройств, серийные номера, названия Wi-Fi, ваш город и координаты, имена, почты, ключи и пароли, пути с именем пользователя. Отдельно посмотрите глазами все картинки из docs/screenshots: в них поиск по тексту ничего не найдёт (город и курсы на экране, названия треков, чужие постеры). В папке не должно быть файлов .apk, .jks, .pass, папок keys, backup, out, .tv-work (там снимки экрана ТВ), файлов config/settings.local.json, .claude/settings.local.json и CLAUDE.local.md.

**Шаг 1. Аккаунт и почта**  
Заведите аккаунт на github.com, если его нет. Затем Settings, Emails: включите «Keep my email addresses private» и «Block command line pushes that expose my email». Тогда в публикации окажется не ваша почта, а адрес вида имя@users.noreply.github.com.

**Шаг 2. GitHub Desktop**  
Скачайте GitHub Desktop (desktop.github.com) и войдите в свой аккаунт. В Settings, Git проверьте, что адрес для коммитов noreply, а не личная почта.

**Шаг 3. Добавить папку**  
File, Add local repository, выберите папку проекта. Когда программа скажет, что репозитория нет, нажмите «create a repository here»: имя (например glasstv), Git ignore None (в папке уже есть свой .gitignore), License None (свой LICENSE уже в папке). Откройте вкладку Changes и посмотрите список файлов: ни одного .apk, .jks, ничего из keys, backup, out, .tv-work.

**Шаг 4. Первый коммит и публикация (сначала приватно)**  
Внизу слева в поле «Summary» напишите «Первый выпуск», нажмите Commit to main, затем Publish repository. Галочку «Keep this code private» ОСТАВЬТЕ: сначала публикуем приватно.

**Шаг 5. Посмотреть и открыть**  
Repository, View on GitHub. Пролистайте страницу глазами: картинки, README, нет ли личного, открываются ли ссылки на документы. Если всё в порядке: Settings, внизу Danger Zone, Change visibility, Make public. Ссылка для друзей это адрес из строки браузера: https://github.com/ВАШ_НИК/glasstv.

Если нашли личное уже после публикации: сначала сделайте репозиторий снова приватным (Settings, Change visibility), потом уберите файл, и учтите, что в истории он остаётся: проще создать репозиторий заново, чем чистить историю.
