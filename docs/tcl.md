# Привязки к TCL и что делать на других ТВ

Все команды ниже проверены на TCL 65C6K (Android TV OS 14) и только на чтение. Мастер запускает их на шаге «паспорт ТВ» и записывает выводы в backup/<метка>/caps.json. Это неофициальные интерфейсы: после обновления прошивки они могут измениться.

**Это TCL?**  
`getprop ro.product.manufacturer`: TCL  
`getprop ro.tcl.product_type`: GTV  
`getprop ro.product.model`: у проверенной модели «Smart TV Pro»  
`getprop ro.hardware`: у проверенной модели mt5896  
`getprop ro.product.cpu.abilist`: у проверенной модели armeabi-v7a,armeabi (32-бит: чужие приложения без сборки под armeabi-v7a не встанут, мастер предупреждает)  
`getprop ro.build.version.sdk`: нужно 28 и больше (Android 9), проверено на 34 (Android 14)  
Не TCL: профиль `generic-gtv`, всё ниже проверяется по пунктам, лишнее отключается.

**Подсветка панели (для «Ночного режима», «Картинки», ночи «Сторожа»)**  
Приложения вызывают отражением класс `com.tcl.tv.pq.TvBacklightManager` из библиотеки прошивки `com.tcl.tv.display` (в манифестах «Сторожа» и «Ночного режима» она подключена как необязательная).  
Проверка: `pm list libraries | grep -x library:com.tcl.tv.display` должно вернуть `library:com.tcl.tv.display`; `service list | grep tcl_tv_display` вернёт строку со службой `com.tcl.tv.display.ITvDisplayManagerService`.  
Живая проба после установки: `am broadcast -n app.glasstv.guard/.Cmd --es do bl` и `adb logcat -d -s guard` (число подсветки; минус один значит, что служба недоступна).  
Нет библиотеки:
- «Картинку» не ставить (она целиком на этом интерфейсе)
- «Ночной режим» остаётся с затемнением поверх картинки
- «Сторож»: ночной ход подсветки заменяется тёмной вуалью, и только если человек согласен на «ночью экран темнее с 22:00 до 07:00»; иначе выключить ночь: кнопка «Ночная подсветка вкл/выкл» на экране «Сторожа» (команды для этого у «Сторожа» нет; ответ мастер записывает в night.enabled)
- автоматику картинки не включать

**Dolby (для «Звука»)**  
Проверка: `pm list packages | grep dolby` ждёт `com.dolby.android.audio.service` и `com.dolby.android.audio.calibration`, библиотека `com.dolby.android.audio`.  
Что делает проба: вручную через службу Dolby выставляет чёткость речи (0..12), режим и силу выравнивания громкости (0..10). Громкие режимы сжатия и понижающее смешение не трогаем: откат только перезагрузкой. Регистрацию в службе не вызываем.  
Нет пакета: у «Звука» пропадают ползунки Dolby, остаётся общий выравниватель Android (сессия 0).  
На ТВ других производителей не проверено. После установки мастер читает `am broadcast -n app.glasstv.guard/.Cmd --es do eq --es a state`, и если эффект не подхватился, предлагает убрать «Звук».

**Кнопки пульта**  
На TCL спецкнопки приходят кодами 4xxx из таблицы прошивки. Таблица: `/tclconfig/tvcust/aio_resources/resource/common_overseas/input_key/shortcutkey.tkl` (рядом shortcutkey.pb). Формат строк: `key <скан-код> <код Android> <имя>`. Примеры строк:
```
key 751 4100 TCL_OKKO
key 566 4062 TCL_NETFLIX
key 752 4099 TCL_PRIMEVIDEO
key 456 4020 TCL_QUICK_MENU
key 588 4082 TCL_ALL_APP
key 759 4096 TCL_IQIYI
key 561 83 NOTIFICATION
key 349 297 FEATURED_APP_1
```
Для пульта RC813 (версия для СНГ) проверено: Okko 4100, ivi 4143, Wink 4164, Premier 4185, VK Видео 4186, TCL Channel 4020, шестерёнка 83 (NOTIFICATION), QUICK_SETTINGS 4514 (сама открывает быструю панель).  
В папке resource 68 записей, многие под отдельные модели; какая действует на вашем ТВ, определяется по самой кнопке. Имена на корпусе и метки в таблице могут не совпадать (TCL Channel и TCL_QUICK_MENU это один код 4020).  
Не TCL: таблицы нет. Мастер просит нажать кнопку при открытой записи триггера в Key Mapper («Tap to record trigger», устройство «Any input device»).

**Быстрая панель TCL (таблетка «Панель TCL» и долгая шестерёнка)**  
Проверка: `cmd package query-services --brief -a com.tcl.settings.SHOW_WINDOW` должно вернуть `com.android.tv.settings/com.tcl.settings.ShowWindowService`.  
Запуск: служба `com.tcl.settings.ShowWindowService` с action `com.tcl.settings.SHOW_WINDOW` и extra `Type=quicksettings`. В Key Mapper это форма «Send intent (Service)»: пакет `com.android.tv.settings`, класс `com.tcl.settings.ShowWindowService`, action `com.tcl.settings.SHOW_WINDOW`, extra `Type` со значением `quicksettings`. Если форма «Send intent» на ТВ не открывается, см. раздел про Key Mapper в CLAUDE.md.  
Нет службы: шестерёнку на панель не переназначать. Таблетка «Панель TCL» на других ТВ ничего не открывает (по коду полоса просто закроется; на живом не-TCL ТВ не проверено).

**Чистка пакетов com.tcl.***  
Только если производитель TCL и есть пакеты из data/tcl-packages.tsv (сверять с `pm list packages`, имена точные). В списке 38 пакетов проверенной модели. Уровни: safe для рекламы, витрины и сбора данных TCL, ask для Netflix, Prime, служб Google и справки (по одному, с объяснением), home только для замены главного экрана (раздел ниже). Функция `off` отключает только пакеты из этого списка; пакет не из списка можно отключить лишь по прямому решению человека, по одному.  
Отключать только `pm disable-user --user 0 <пакет>`, партиями до 10, каждый отдельной командой, после партии проверить пульт, HDMI, звук, YouTube, Wi-Fi.  
На не-TCL по умолчанию ничего не отключается: если человек хочет чистить, он сам называет пакеты (списки вроде github.com/Gathin23/cleanyourtv он читает сам), и каждый пакет вне списка отключается только по его решению, по одному.

**Не трогать никогда**  
Список в data/tcl-never-touch.txt. Коротко: основа ТВ (com.tcl.tv), службы входов и тюнера, управление ожиданием, база настроек, первичная настройка, сервисное меню, сопряжение пульта и служба Bluetooth-пульта, служба пульта Google TV, служба местоположения (если её отключить, ТВ уходит в бесконечную перезагрузку), службы Google Play, Play Маркет, клавиатура TCL, всё от MediaTek, голосовой поиск, YouTube для ТВ (нужен для трансляции с телефона), служба пульта TCL.  
Формат файла: одна строка, один пакет (имя целиком или начало имени со звёздочкой, пояснение после знака решётки). Имена сверены со списком проверенной модели; на другой модели сверяйте с `pm list packages` на самом ТВ. Функция `off` из tools/tv.sh отказывается отключать такие пакеты.  
Если после чистки пропали входы или эфирное ТВ: `pm enable --user 0 com.tcl.ttvs` и перезагрузка.

**Замена главного экрана**  
На TCL владелец главного экрана переходит к «Дому» только после отключения `com.google.android.apps.tv.launcherx` и `com.google.android.tungsten.setupwraith`. Пока они включены, `cmd package set-home-activity` пишет Success и ничего не меняет, а кнопка «Домой» потом уходит в экран восстановления.  
Порядок делает функция `home_switch` из tools/tv.sh одной проверяемой операцией: открыть «Дом», записать прежнего владельца, отключить оба пакета, назначить «Дом», проверить владельца и кнопку «Домой». Не сменилось: она сама включает пакеты обратно и возвращает роль. Отдельно функция `off` эти пакеты не отключает.  
Wi-Fi при этом не пропадает: им владеют настройки ТВ.

**Режим питания**  
«Повышенное потребление (Всегда онлайн)» вместо «Низкого потребления»: иначе ТВ в ожидании теряет сеть, и отладка пропадает. Выставляется человеком в меню TCL, adb его не меняет.

**«Картинка» и «Звук» зависят от модели**  
Список режимов картинки взят из настроек конкретной прошивки. На другой модели TCL «Картинку» ставить только после живой пробы `am broadcast -n app.glasstv.guard/.Cmd --es do pq --es a dump` (только чтение, снимок сохраняется в файлы приложения «Сторожа»).

**Что делать на других ТВ**
- Профиль `generic-gtv` (есть leanback и Android 9 или новее): «Дом», «Ночной режим» (затемнение картинкой), «Сторож» без ночной подсветки, плитки, браузер, «Волна»
- «Звук» только если нашлась служба Dolby и проба `do eq` подтвердила эффект
- «Картинку» и ночную подсветку не ставить без библиотеки подсветки
- Чистку не делать; кнопки пульта записывать вручную
- Если не уверены в пакете или команде, остановиться и спросить: вслепую не пробовать
- Не поддерживается: Android TV 11 и старше, Fire TV, Tizen, webOS
