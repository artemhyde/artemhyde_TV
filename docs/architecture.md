# Как устроен HYDE TV

Метки: [общее] верно для любого Google TV, [TCL] особенность прошивки или пульта TCL.

**Идея**  
Компьютер по беспроводной отладке (adb) управляет ТВ без root: установщик hyde-install из архива выпуска (окно мастера в браузере или Claude Code его командами) или Claude Code по шагам CLAUDE.md при сборке из исходников. Прошивка остаётся какая есть. Поверх неё ставятся свои приложения, а у TCL ещё и отключается лишнее. Готовые приложения подписаны ключом выпуска, при сборке из исходников вашим ключом.

**Схема**
```
Компьютер (Claude Code, adb, сборка)
   |  adb по Wi-Fi (беспроводная отладка)
   v
ТВ
  система производителя: входы HDMI, тюнер, Wi-Fi, клавиатура, быстрая панель. Не трогаем
  роли:  главный экран = Дом    заставка Android выключена    слушатель уведомлений = Волна
         админ устройства = Ночной режим (и Key Mapper)
         служба спецвозможностей = Key Mapper (за ней следит Сторож)
         беспроводная отладка = её держит Сторож
  Дом <--broadcast--> Волна --MediaBrowser--> app.glasstv.aura (своя сборка Aura Music, играет звук)
  Звук, Картинка --broadcast--> Сторож (пишет в Dolby и в настройки картинки)
  Key Mapper: кнопки пульта -> приложения
```

**Свои приложения (пакеты app.glasstv.*, один ключ подписи)**

| Пакет | Что делает | Как открывается |
|---|---|---|
| app.glasstv.home «Дом» | Главный экран и экран блокировки: фото по времени суток, часы, погода, курсы (по желанию), стих, плитки, «Все приложения». Полоса таблеток на шестерёнку | Главный экран; невидимый вход «Быстрая полоса» для Key Mapper |
| app.glasstv.guard «Сторож» | Служба переднего плана: беспроводная отладка, Key Mapper, зажатая громкость при включённом Key Mapper (его фильтр съедает повторы кнопки), подсветка на границах 22:00 и 7:00, таймер простоя, умный звук, картинка по времени, возврат на главный экран, присмотр за частным DNS (`DnsWatch`), обновления приложений не из Google Play раз в сутки (`Updates`, список `assets/updates.txt`; без нажатий, если установщик «Сторож» и приложение собрано под Android 12+). Паспорт ТВ (`Caps`: производитель, серия, прошивка, уровень «проверено», «экспериментально» или «не TCL»; закрытые вызовы TCL только на TCL, служба Dolby только при той же версии и хэше интерфейса; после смены прошивки проверка заново), отчёт без личных данных (`Report`, `Scrub`), часы ночи из настроек. Команды: вход `.Cmd` с правом DUMP (adb с компьютера) и вход `.AppCmd` с правом `app.glasstv.permission.GUARD` по подписи (свои приложения: «Звук», «Картинка», «Дом», «Ночной режим») | Запускается сам при загрузке (вручную: `am broadcast -n app.glasstv.guard/.Boot`); экран состояния; команды `am broadcast` |
| app.glasstv.nightmode «Ночной режим» | Плашка с одним ползунком яркости 1:1 (подсветка панели и красная зона до −100 %: два слоя вуали), вторым нажатием полное меню: таймер сна, тёплый свет. Служба живёт только для красной зоны и таймера. В конце сна `lockNow` | Плитка, полоса таблеток, кнопка пульта. Права: SYSTEM_ALERT_WINDOW, WRITE_SETTINGS, админ устройства |
| app.glasstv.sound «Звук» | Полоса поверх фильма: режимы и ползунки Dolby | Полоса таблеток, кнопка пульта, кнопка в «Ночном режиме» |
| app.glasstv.picture «Картинка» | Полоса поверх фильма: режимы и ползунки картинки TCL | Полоса таблеток, кнопка пульта |
| app.glasstv.volna «Волна» | Музыка через Aura Music: «Моя волна», «Новое для вас», тексты, профили вкуса | Плитка, карточка из полосы таблеток; слушатель уведомлений держит процесс живым |
| app.glasstv.tile.* | Ярлыки без экрана (браузер, видео, фильмы, файлы и др.): открывают настоящее приложение и закрываются. Единые плитки, обновления чужих приложений плитки не ломают | LAUNCHER и LEANBACK, цель в meta-data `target` |
| app.glasstv.clip «Вставка» | Кладёт присланный с компьютера текст в буфер ТВ (base64 в extra `b64`) | Только скрипт tools/paste-to-tv.sh |
| app.glasstv.keyboard «Клавиатура» | Экранная клавиатура для пульта: ряд цифр всегда, верхний ряд по типу поля, заглавная, стирание и язык удержанием, строка с текстом и курсором. Без разрешений, ничего не пишет и не хранит | Включается `ime enable` и `ime set`, откат `ime set <прежняя>` |

Браузер HYDE Browser (TV Bro с нашими правками) собирается отдельно (tvbro/), живёт под своим пакетом `app.glasstv.browser` рядом с обычным TV Bro.

**Роли и права (всё без root, выдаётся с компьютера)** [общее]
- Главный экран: `cmd package set-home-activity app.glasstv.home/.HomeActivity`, проверка `cmd role get-role-holders --user 0 android.app.role.HOME`
- Заставка Android выключена: `settings put secure screensaver_enabled 0`, `screensaver_activate_on_sleep 0`, `screensaver_activate_on_dock 0`, `settings put system screen_off_timeout 2147483647`. Простой ведут «Дом» (`FLAG_KEEP_SCREEN_ON`, 1 минута на плитках, 5 в сетке) и «Сторож» (раз в минуту читает `dumpsys power`: 10 минут без нажатий, нет замка экрана и видео, тогда главный экран с extra `idle`)
- Слушатель уведомлений: `cmd notification allow_listener app.glasstv.volna/app.glasstv.volna.Listener`
- Админ устройства: `dpm set-active-admin app.glasstv.nightmode/.AdminReceiver` (нужен для блокировки экрана в конце таймера)
- Служба спецвозможностей: Key Mapper; «Сторож» перезапускает её, переписывая `enabled_accessibility_services` (право WRITE_SECURE_SETTINGS)
- appops: SYSTEM_ALERT_WINDOW (NightMode, Volna, Guard), WRITE_SETTINGS (NightMode, Guard), GET_USAGE_STATS (Home), AUTO_START (Home, Volna, Guard, Aura Music; на TCL без него автозапуск режется), ASSOC_START (Aura Music; на TCL без него журнал пишет `forbid bind service`, служба застревает в ожидании перезапуска, и музыка встаёт насовсем)
- `pm grant`: WRITE_SECURE_SETTINGS (Guard, Key Mapper), DUMP (Guard, таймер простоя), POST_NOTIFICATIONS (NightMode)
- Белый список Doze: `dumpsys deviceidle whitelist +<пакет>`
- Компиляция: `pm compile -m speed -f <пакет>` после каждой установки

**Как приложения связаны**
- Дом и Волна: «Дом» шлёт `am broadcast -n app.glasstv.volna/.Cmd --es do home_on|home_off|my`, «Волна» шлёт «Дому» на приёмник `.Now` extras `playing`, `title`, `artist` и `hello`
- Волна и плеер: MediaBrowser к службе `com.auramusic.app.playback.MusicService` в пакете `app.glasstv.aura`. Трек: `playFromMediaId("id/<videoId>/<название>/<исполнитель>/<мс>")`, ответ сразу, без поиска и базы. Стоп: `sendCustomAction("ACTION_HARD_STOP")`, плеер пуст, и до следующей явной команды любой `play()` отклоняется. Заранее: `VOLNA_PRELOAD` (адрес потока следующего трека). Аккаунт: `sendCommand` с `VOLNA_PROFILE`, `VOLNA_FEED` (home, liked, radio), `VOLNA_LIKE` (1, 0, -1), `VOLNA_WHOAMI`, ответ JSON строкой без кук. Второй профиль это канал того же аккаунта с тем же именем (заголовок `X-Goog-PageId`), нет такого канала: оценка не отправляется. Команды принимаются только от пакета «Волны» с той же подписью.
- Звук и «Сторож»: `am broadcast -n app.glasstv.guard/.Cmd --es do eq --es a state|set`, extras `preset` (kino, music, night, clean, custom), `de` 0..12, `vl` 0..10, `bass` и `treble` от −5 до +5; ответ JSON в resultData. Значения «Сторож» хранит у себя, Dolby пишется только изменившимся ключом
- Свои приложения шлют «Сторожу» на `.AppCmd` (право по подписи), с компьютера те же команды идут на `.Cmd`. Новые команды: `--es do caps` (паспорт ТВ), `--es do report [--ez save true]` (отчёт без личных данных), `--es do idle` (что видит таймер простоя), `--es do nighthours [--ei from 18..23 --ei to 5..10] [--ez enabled true|false]` (часы ночи), `--es do svc [--es url … --es pkg … --es name …]` (присмотр за локальным сервером), `--es do adb [--es m always|service|off]` и `--es do notes --ez on true|false` (выключатели)
- Картинка и «Сторож»: `--es do pic --es a state|set|reset`, extras `preset` (kino, day, hdr, soft), `backlight` 5..100, `black` 0..2, `peak` 0..3, `warm` −5..5. Выбор держится до границы 22:00 или 7:00
- Автоматика картинки «Сторожа»: `--es do pq --es a dump|apply|restore|auto`, `dump` только читает
- «Сторож», остальное: `--es do bl` (прочитать подсветку), `--es do sound` (умный звук), `--es do night --ez on true|false` (отработать границу 22:00 или 7:00), `--es do home` (на главный экран). Итог команд в `adb logcat -d -s guard`
- Ночной режим с компьютера: `am start -n app.glasstv.nightmode/.MainActivity --ei seconds 70` (запуск таймера), `--ez unadmin true` (снять права админа перед обновлением)
- Полоса таблеток: активность `app.glasstv.home/.PillsActivity` в своей задаче, невидимый вход `.PillsLaunch` для «Launch app» в Key Mapper

**Сборка без Gradle** [общее]  
Один конвейер на все приложения (build/build-app.sh): `aapt2 compile`, `aapt2 link` (minSdk 31, targetSdk 34), `javac --release 8 -classpath android.jar`, `d8`, добавление classes.dex в APK (aapt2 его не кладёт), `zipalign`, `apksigner`. Настройки человека (город, тема, курсы, стихи, имя второго профиля) подставляет build/gen-config.sh в Config.java. Ключ один на все приложения: подпись должна совпадать у связанных приложений и при обновлении. Браузер собирается Gradle из исходников TV Bro плюс наши патчи.

**Установка и обновление**  
Приложения ставятся `adb install -r` из out/. Если установка виснет на подтверждении, файл кладётся в /data/local/tmp и ставится `pm install -r -g` в оболочке ТВ. Перед обновлением приложения с правами администратора права снимаются (NightMode: `--ez unadmin true`, Key Mapper: настройки безопасности), потом ставится новая версия, потом права возвращаются. Причина: переустановка с активным админом вешает систему примерно на 70 секунд, сторожевой таймер перезапускает ТВ, пропадают права и отладка. [общее]

**Данные и сеть**  
Что приложения запрашивают в интернете:
- api.open-meteo.com: погода по вашим координатам
- upload.wikimedia.org: фото для экрана блокировки (список в res/raw/photos.json, автор и лицензия показываются на экране)
- api.nbrb.by: курсы Нацбанка Беларуси, только если включили
- music.youtube.com: подборки «Волны», анонимно, без входа
- lrclib.net: тексты песен
- api.github.com, gitlab.com и страницы выпусков (github.com, auroraoss.com): «Сторож» раз в сутки проверяет новые версии приложений не из магазина, которые у вас стоят (список apps/guard/assets/updates.txt), и оттуда же их качает
- 1.1.1.1 и 8.8.8.8: «Сторож» раз в 5 минут при включённом экране проверяет, есть ли интернет (только соединение, без данных), и спрашивает у DNS вашего ТВ случайное имя на github.io или blogspot.com. Интернет есть, а имена не открываются: он спрашивает защищённые DNS напрямую (Mullvad, Cloudflare, AdGuard, Google) и ставит рабочий
- i.ytimg.com: обложки  
Сам мастер при установке один раз обращается к geocoding-api.open-meteo.com с названием города и скачивает файлы по списку data/third-party-sources.json. Установщик hyde-install ходит наружу только по согласию человека: adb с dl.google.com (если его нет на компьютере) и Key Mapper с GitHub автора; остальное время он говорит только с телевизором. Всё перечисленное выше идёт уже с вашего ТВ, от приложений: например api.open-meteo.com получает координаты вашего города, поэтому «координаты остаются у вас» было бы неправдой. Город и координаты лежат в config/settings.local.json, в вашем APK и на вашем ТВ. Отдельно «Сторож» может держать страницу записок с телефона на порту 8765 в домашней сети (записку она принимает только с кодом из шести цифр с экрана «Сторожа»): это входящие запросы, наружу она ничего не шлёт.

**Файлы проекта**
- apps/: исходники приложений (home, guard, nightmode, sound, picture, volna, tiles, clip, keyboard)
- shared/fonts/: шрифт Inter с текстом лицензии OFL
- build/: сборка и подпись (env.sh, gen-config.sh, build-app.sh, build-all.sh, new-key.sh, sign.sh, check-apk.sh)
- tvbro/: патчи к TV Bro, текст его лицензии, скрипт сборки
- tools/: поиск ТВ, снимок и откат, вставка текста, зеркало экрана, двойник пульта (rc-double)
- installer/: установщик одной программой (Go): поиск ТВ, паспорт, план, установка с журналом, продолжение после обрыва, проверка, откат, adb с сайта Google по согласию, окно мастера в браузере; рецепт установки recipe.json, путь Claude AGENT.md, README.txt архива в dist/ (installer/README.md). Архивы выпуска собирает build/package.sh
- data/: список пакетов TCL, список «не трогать», источники чужих приложений
- config/: образец настроек (рабочий файл создаёт мастер и в git он не попадает)
- docs/: документация

**Ограничения Android 14** [общее]
- Приложение не может закрывать чужие: killBackgroundProcesses действует только на свои процессы (проверено и на Aura Music: её процесс остаётся, сбрасывается только плеер)
- Окна-накладки с флагом NOT_TOUCHABLE ограничены прозрачностью 0,8: поэтому ночное затемнение делится на 0,8, а значок отсчёта делается окном без этого флага
- Служба переднего плана требует тип (specialUse с описанием), чужие приложения видны только через `<queries>`, низкий targetSdk блокируется, нужно право на уведомления
- Картинка в картинке на некоторых прошивках вырезана (проверка `pm has-feature android.software.picture_in_picture`)
- Подключить Bluetooth-наушники одной кнопкой из обычного приложения нельзя: можно только открыть экран настроек
- Телевизор приглушает экран по бездействию: будить `KEYCODE_WAKEUP`
- Когда ТВ спит, система режет приложениям интернет: сеть проверять при включённом экране

**Опасные места** [общее]
- Перезагрузка или смена Wi-Fi закрывает беспроводную отладку. Без неё компьютер до ТВ не достанет, поэтому «Сторож» держит её включённой
- `screen_brightness` равный 1 на некоторых панелях даёт нулевую подсветку: нижний предел 10
- Несколько `pm` подряд в одной команде могут остановиться после первой: отключать пакеты по одному
- `adb shell` с конвейером внутри кавычек: кавычить всю удалённую команду целиком
- Касания `input tap` переводят ТВ в режим касаний, обычная передача фокуса перестаёт работать (в своих меню используется `requestFocusFromTouch`)
- Двойник пульта через `hid` нужен потому, что Key Mapper не принимает `input keyevent`, а запись в /dev/input запрещена системой
- Беспроводная отладка и записки «Сторожа» доступны устройствам домашней сети: подтверждайте запросы только на ТВ и только если ждёте их

**Как проверять результат**  
`adb exec-out screencap -p` (снимок; на защищённом видео и HDMI кадр бывает пустым, это защита), `uiautomator dump` (разбор текста и координат), `dumpsys activity activities | grep topResumedActivity` (что на экране), `dumpsys window | grep mCurrentFocus`. Плавность по снимкам не видна, её смотрят на самом ТВ.
