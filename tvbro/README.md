**HYDE Browser: браузер TV Bro с нашими правками**
Что это: готовых файлов браузера здесь нет, только патчи (разности к исходникам) и скрипт сборки. Исходники TV Bro скачиваются с GitHub автора, патчи накладываются, браузер собирается у вас на компьютере и подписывается вашим ключом. Готовый файл бывает ещё в выпуске (docs/release.md).
Автор оригинала: Fedir Tsapana, проект github.com/truefedex/tv-bro. Текст его лицензии лежит рядом: `LICENSE-TVBro.md`.

**Лицензия TV Bro и HYDE Browser**
Изменённую сборку TV Bro можно передавать, только если у неё своё название без «TV Bro», свой значок, свой идентификатор приложения и окно «О программе» с текстом, что она сделана на исходниках TV Bro, и ссылкой на github.com/truefedex/tv-bro. Это делает последний патч `10-hyde-browser`: название HYDE Browser во всех языках, глобус на графите вместо значка и баннера TV Bro, пакет `app.glasstv.browser`, строка в «Настройки», «О программе». Поэтому собранный HYDE Browser можно передавать другим.
Без патча 10 получится `out/tvbro.apk` с прежним именем и значком: такой файл только для вашего ТВ.

**Что дают патчи**
`01`: страница остаётся под плеером, когда играет видео
`02`, `02a`, `02b`: плееры внутри страниц (сторонние куки, смешанное содержимое, Widevine, блокировщик по кадру, режим без сторонних куки)
`03`, `04`: удобство (панель адреса по «Вверх» на верху страницы, подсказки, прокрутка на 40 %, кнопка «Найдено видео», исправления и проверки)
`05`: окна сайтов в фоне, автозапуск видео по умолчанию, подсказки Google без фильтра по началу слова
`06`: «Графит» в браузере: стеклянные верхняя панель и вкладки, кнопка «Поиск», стартовая страница
`07`: плоский стиль поверх 06: одна ровная тёмная панель вместо стекла
`08`: отдельное окно для правки адреса с жёлтым курсором
`09`: журнал: фокус не уходит на панель под экраном
`10`: HYDE Browser (условия лицензии TV Bro, см. выше)
Проверена вся цепочка подряд (01 до 10) на коммите `52b078f`. Если убрать часть патчей, цепочку нужно проверить заново: `bash tvbro/build-tvbro.sh --patches-only`.

**Что нужно для сборки**
git, JDK 21, Android SDK с платформой и build-tools 36, ваш ключ подписи (`bash build/new-key.sh`).
Загрузки: около 2,4 ГБ (кэш Gradle) при первой сборке.
Папка репозитория: держите её недалеко от корня диска (например `C:\glasstv`). Самый длинный файл TV Bro имеет путь в 113 символов, а на Windows путь свыше 260 не открывается: в глубокой папке упрётся и клонирование (скрипт включает для него `core.longpaths`), и Gradle (его настройка git не лечит).
Лицензию Android SDK принимаете вы сами. Мастер ставит инструменты в `~/.glasstv/tools` только после вашего «да».

**Как собрать**
`bash tvbro/build-tvbro.sh`
Скрипт клонирует исходники в `out/tvbro-src` с ключами `-c core.autocrlf=false -c core.longpaths=true`, переходит на коммит `52b078f`, проверяет и накладывает патчи по порядку имён, убирает растровые значки TV Bro, собирает вариант `fossGeckoExcludedRelease` на JDK 21 и подписывает `out/hyde-browser.apk` вашим ключом.
Быстрая проверка без сборки: `bash tvbro/build-tvbro.sh --patches-only` (скачает исходники и наложит патчи, Gradle не запускается).
Установка на ТВ: делает мастер (`inst out/hyde-browser.apk app.glasstv.browser`), HYDE Browser встаёт рядом с обычным TV Bro из Google Play.

**Если патчи не ложатся**
Причина почти всегда в окончаниях строк. Патчи содержат символы CRLF, и их нельзя переписывать редактором. На Windows при глобальной настройке git `core.autocrlf=true` патчи не накладываются: скрипт отключает её только для своего клона, но сами файлы патчей должны остаться такими, как скачаны. Скачайте репозиторий заново архивом (Code, Download ZIP) и не открывайте патчи в редакторе с сохранением.
Коммит закреплён: если автор TV Bro изменит проект, наши патчи продолжат ложиться на проверенный коммит.

**Обновление и удаление**
Обновление: та же сборка и `adb install -r` (правило про приложения с правами администратора описано в CLAUDE.md, шаг 7).
Удаление: `adb shell pm uninstall app.glasstv.browser` или через Настройки, Приложения. Папку `out/tvbro-src` можно просто стереть.
Прежняя своя сборка с пакетом `com.phlox.tvwebbrowser.foss` с HYDE Browser не конфликтует: это два разных приложения, закладки между ними не переносятся.
